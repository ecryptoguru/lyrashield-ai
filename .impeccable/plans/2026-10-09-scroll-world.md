## Integration work required

The supplied engine is a reference implementation, not a drop-in production module:

- Extract injected CSS into Astro/CSS assets compatible with the current CSP.
- Preserve server-rendered content and a useful no-JS/static fallback.
- Add lifecycle cleanup for listeners, observers, animation frames and blob URLs.
- Bound blob/video memory and prefetch; avoid retaining the whole film on phones.
- Stop frame work when hidden/offscreen; coalesce seeks and gate painted frames.
- Preserve previous fixes: native navigation, stable layout and accessible focus.
- Phone URL-bar resizes must not rebuild scroll geometry; rotation must work.
- Respect reduced motion and Save-Data before media downloads.
- Use remote immutable media publishing only after the existing publication gate.

Acceptance: inspect every seam in both directions; interrupt scroll mid-seek;
verify decoded frame readiness, loading/failure fallback, native portrait selection
if approved, both themes, keyboard access, reduced motion and CPU-throttled mobile.
Physical iOS Safari remains a separate device check where available.
