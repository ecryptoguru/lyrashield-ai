# LyraShield AI Power

LyraShield AI connects Kiro to an OAuth-backed MCP server for evidence-backed release
assurance. The default connection is read-only and is scoped to one selected workspace.
Write actions require the `lyrashield.write` scope and LyraShield's exact-argument approval.

## Privacy

Only the data needed for the requested workspace operation is sent to the hosted service.
Tokens, prompts, targets, findings, and report contents are not written to marketplace
telemetry. See [Privacy](https://lyrashieldai.com/privacy).

## Support

Setup help and issue reporting are available at [Support](https://lyrashieldai.com/support).
Security reports must use the separately published security-reporting address.

This Power is Apache-2.0 client tooling; the hosted LyraShield service remains proprietary.
