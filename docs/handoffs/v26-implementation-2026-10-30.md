The comparison supports keeping the existing automatic start and completed-decoder reuse. Cache behavior materially changes the return tradeoff. Ephemeral-profile cases without retained film cache showed D5 return delays measured in seconds. A fresh persistent-profile portrait probe demonstrated genuine native HTTP cache hits (`transferSize=0`), one server film body total, and return delays measured in tens of milliseconds (approximately 55–61ms for D5 versus 20–21ms existing). A repeat wire download is therefore **not inevitable**. These bounded local samples do not establish statistical superiority, production CWV, physical-device smoothness or memory/RSS savings. Visibility results are controlled handler approximations. No film was regenerated or production behavior changed.
